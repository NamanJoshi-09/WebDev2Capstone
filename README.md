# Trackify — Subscription Tracker

A modern fintech-inspired subscription management dashboard built as a university capstone project.

## Tech Stack
- React 18 + Vite
- Tailwind CSS (custom dark design system)
- React Router DOM v6
- Context API (Auth, Subscriptions, UI)
- Axios + ExchangeRate-API
- React Toastify, React Icons, date-fns

## Features
- 🔐 Mock Authentication (localStorage)
- 📊 Dashboard with spending analytics
- ➕ Full CRUD for subscriptions
- 🔔 Renewal reminders (7-day alerts)
- 🔍 Debounced search, filter, sort
- 📄 Pagination
- 📅 Renewal Calendar
- 💱 Live currency conversion (ExchangeRate-API)
- 🌑 Dark fintech UI
- 📱 Fully responsive

## Getting Started

```bash
npm install
npm run dev
```
